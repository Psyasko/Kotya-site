# Останні зміни

- Вимкнено автоматичні переноси та розриви слів усередині слова.
- Збільшено безпечні внутрішні відступи органічних панелей.
- Відцентровано текст та іконки у блоці «Підхід».
- Перебудовано інформаційну панель місця роботи, щоб `DeMassage` не розривалося по літерах.
- На мобільних збережено чотири різні асиметричні форми карток.
- Термін «клініка» замінено на «студія» у видимому тексті та метаданих.
- Відновлено коректний `package-lock.json` і перевірено чисту збірку через `npm ci` та `npm run build`.
