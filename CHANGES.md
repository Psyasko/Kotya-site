# Основні зміни версії 2.0

- Повністю переписано CSS без накопичених repair-патчів.
- Стилі розділено на tokens, base, layout, components, motion і responsive.
- Hero перебудовано навколо імені Катерини та фото в органічній масці.
- Додано каліграфічний dragon route, азійські хмарні завитки й ботанічні контури.
- Усі картки переведено на систему safe-area: декоративна форма не впливає на текст.
- Створено окрему мобільну композицію без довгого dragon route і горизонтального overflow.
- Viber прибрано, оскільки номер не наданий; Telegram активний.
- Додано мобільне меню, focus-стани, scroll-margin, alt-текст і reduced-motion.
- Оптимізовано фото у трьох WebP-розмірах.
- Додано favicon, Open Graph, meta description та schema.org Person.
